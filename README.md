# Eva KB — просмотр офлайн-отчётов `.evakb`

**По сути это безопасная офлайн-смотрелка HTML для автономных дашбордов.**
Приложение не делает ничего, кроме одного: берёт присланный файл `.evakb`
(обычный ZIP с самодостаточным HTML внутри), распаковывает его в приватный
каталог и показывает `index.html` в WebView без доступа к сети.

Маленькое Android-приложение: открывает пакет `.evakb`, полученный из VK,
мессенджера или файлового менеджера, и показывает вложенный автономный
HTML-дашборд (вместе с графиками на JavaScript) в WebView.

Ни сервера, ни аккаунтов, ни синхронизации, ни базы данных, ни аналитики.
Разрешение `INTERNET` приложением **не запрашивается вообще**.

Лицензия — [MIT](LICENSE).

- Идентификатор пакета: `ai.eva.kbviewer`
- minSdk 24, targetSdk/compileSdk 35
- Kotlin + Gradle, без AndroidX и без сторонних библиотек в рантайме

## Формат `.evakb`

`.evakb` — это обычный ZIP-архив:

| Путь | Обязательность | Назначение |
|---|---|---|
| `index.html` | **обязателен**, только в корне | точка входа дашборда |
| `manifest.json` | необязателен | метаданные пакета |
| `assets/**` | необязательно | CSS, JS, картинки, шрифты |
| `data.json` | необязательно | данные отчёта |

`manifest.json`:

```json
{
  "format": "eva.kb",
  "version": 1,
  "title": "База знаний Eva — сводка",
  "generatedAt": "2026-08-21T09:30:00Z"
}
```

Если `manifest.json` есть, он должен быть корректным JSON-объектом,
`version` должен быть равен `1`, а `format` — либо отсутствовать, либо быть
равным `eva.kb`. Заголовок из `title` показывается в шапке экрана просмотра.

### Ограничения при открытии

Приложение отказывается открывать пакет, если:

- путь записи выходит за пределы архива (zip-slip: `..`), абсолютный
  (`/etc/...`, `C:\...`), содержит `\` или байт `NUL`;
- записей в архиве больше **300**;
- сам файл больше **25 МиБ**;
- суммарный размер распакованного содержимого больше **75 МиБ**;
- в корне нет `index.html`;
- `manifest.json` повреждён или объявляет неподдерживаемую версию формата;
- структура архива противоречива (например, запись-файл `assets` и запись
  `assets/app.js` «внутри» неё).

В любом из этих случаев на стартовом экране появляется короткое сообщение
об ошибке на русском — приложение не падает.

### Что запрещено содержимому пакета

- Любые сетевые запросы (`http`, `https`, WebSocket и прочее) блокируются:
  разрешения `INTERNET` нет, в WebView выставлены `blockNetworkLoads` и
  `blockNetworkImage`, а `shouldInterceptRequest` возвращает пустой ответ на
  всё, что не является файлом внутри распакованного пакета.
- Доступ к файлам вне каталога распаковки, `allowUniversalAccessFromFileURLs`
  и `allowFileAccessFromFileURLs` выключены; `content://` из WebView недоступен.
- JS-мостов (`addJavascriptInterface`) нет.
- Внешняя ссылка (`http`/`https`) открывается в системном браузере **только**
  после явного нажатия пользователем (`request.hasGesture()`); автоматические
  переходы и подзапросы отбрасываются.
- JavaScript при этом **включён** — без него не работают графики.

## Сборка

Нужны JDK 21 (подходит JBR из Android Studio) и Android SDK с платформой 35.

Путь к SDK Gradle берёт из `local.properties` (файл не в git — создайте его
рядом с `settings.gradle.kts`) либо из переменной `ANDROID_HOME`:

```
sdk.dir=D:/Programs/AndroidSDK
```

```powershell
$env:JAVA_HOME = "D:\Programs\AndroidStudio\jbr"
.\gradlew.bat assembleDebug
```

Результат: `app/build/outputs/apk/debug/app-debug.apk`,
копия для раздачи — `dist/eva-kb-viewer-debug.apk`.

Тесты:

```powershell
.\gradlew.bat testDebugUnitTest          # JVM-тесты валидатора и распаковщика
python -m unittest discover -s tools     # тесты упаковщика
```

## Установка на устройство

```powershell
D:\Programs\AndroidSDK\platform-tools\adb.exe install -r dist\eva-kb-viewer-debug.apk
```

## Как открыть пакет

1. **Из приложения.** Запустить Eva KB → «Открыть файл .evakb» → выбрать файл
   в системном диалоге.
2. **Из VK или файлового менеджера.** Нажать на присланный файл `.evakb` и
   выбрать Eva KB в списке приложений. Приложение объявляет четыре фильтра
   `ACTION_VIEW`:
   - собственный MIME `application/vnd.eva.kb+zip`;
   - путь `*.evakb` **без** MIME-типа — для интентов, где тип не указан;
   - путь `*.evakb` с `mimeType="*/*"` — для интентов, где тип указан
     (фильтр без `mimeType` такие интенты не ловит вообще, а VK и многие
     файловые менеджеры MIME подставляют всегда);
   - `application/zip` / `application/x-zip-compressed` /
     `application/octet-stream` — только для схемы `content://`, потому что
     так VK отдаёт вложения, у которых расширение в URI не видно.

   Расширение `.evakb` в двух средних фильтрах обязательно, поэтому чужие
   файлы приложение на себя не забирает. Тип содержимого всё равно
   проверяется уже внутри приложения.

Аппаратная кнопка «назад» листает историю WebView, а когда история кончилась —
возвращает на стартовый экран.

## Сборка пакета `.evakb`

Упаковщик — на чистой стандартной библиотеке Python 3:

```powershell
python tools\build_evakb.py sample dist\sample-dashboard.evakb
python tools\build_evakb.py sample dist\sample-dashboard.evakb --force   # перезапись
```

- проверяет наличие `index.html` в корне и корректность `manifest.json`;
- если `manifest.json` нет — генерирует его (`--title` задаёт заголовок);
- соблюдает те же лимиты, что и приложение;
- **никогда** не перезаписывает существующий файл без `--force`;
- выдаёт детерминированный ZIP: записи отсортированы, время фиксировано
  (1980-01-01), права и `create_system` одинаковые на любой ОС, — поэтому две
  сборки одного каталога побайтово совпадают.

## Пример

`sample/` — автономный дашборд: заголовок и время обновления, две карточки с
показателями, столбиковая диаграмма на чистом JS (SVG строится в
`assets/app.js`, без CDN и без сети) и переключение разделов
«Обзор / Динамика / Данные». Раздел можно открыть сразу ссылкой вида
`index.html#dynamics`. Данные захардкожены в `assets/app.js`: при `file://`
запросы XHR к соседним файлам запрещены, поэтому `data.json` в пакете —
человекочитаемая копия того же набора, а не источник для загрузки.

Готовый пакет: `dist/sample-dashboard.evakb`.
